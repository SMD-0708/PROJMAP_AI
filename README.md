# PROJMAP_AI
ProjMap-AI 是一款开源的智能项目认知脉络系统，专门解决 AI 编程助手的“上下文遗忘与污染”问题。在 Cursor、通义灵码等 AI 工具日益普及的今天，AI 如何记住项目全貌、理解主线逻辑、追溯历史决策，始终是一个黑盒难题。ProjMap-AI 的创新在于：将 AI 对项目的隐式记忆转化为可视、可控、可校准的“白盒认知地图”。  核心机制包括：自动扫描项目并生成脉络图、路径状态机区分主线与休眠分支、五档信任梯度保护代码隐私、关键决策点记录实现可追溯、待确认机制支持人机双向校准。项目内置金融科技、科研数据分析、软件开发三大领域技术标签词库，深度适配不同场景。
适用场景包括团队项目交接、复杂代码快速上手、科研过程追溯、AI 辅助开发上下文管理等。项目已发布至 PyPI，采用 MIT 许可证，完全免费开源。
目前项目的 LLM 语义增强功能已针对 DeepSeek API 做了完整测试，推荐优先使用。理论上 ProjMap-AI 支持兼容 OpenAI 接口的其他大模型（如通义千问、GPT 等），但因精力有限，尚未对其他模型做充分验证，使用其他 API 时可能出现返回格式差异。欢迎社区贡献者参与适配测试。
PyPI 地址：https://pypi.org/project/projmap-ai/
